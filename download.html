SovereignMind installieren

Ein Installer richtet alles ein, ohne Docker und ohne WSL. Wählen Sie Ihr Betriebssystem.

Installer herunterladen

Die Datei SovereignMind-Setup-<Version>.exe aus den Release-Dateien laden und als Administrator ausführen.

Voraussetzungen

  • Windows 10 (1809), Windows 11 oder Server 2019+ (x64)
  • Administratorrechte
  • Ollama und die KI-Modelle liefert der Installer mit; kein Internet für die Installation nötig
  • Empfohlen: GPU mit ausreichend VRAM; ohne GPU läuft alles auf der CPU, deutlich langsamer.
  • Ein Lizenzschlüssel (Token) und die E-Mail-Adresse, auf die er ausgestellt wurde
Optional: Der Hardware-Agent (Windows-Dienst für echte CPU-/RAM-/GPU-Werte im Hardware-Dashboard) ist im Setup als Aufgabe wählbar.

Pakete herunterladen

Beide .deb-Dateien aus den Release-Dateien laden und im selben Ordner installieren:

Voraussetzungen

  • Ubuntu 24.04 oder Debian 12 (x64)
  • sudo-Rechte
  • Empfohlen: GPU mit ausreichend VRAM (NVIDIA oder AMD); sonst CPU, deutlich langsamer.
  • Ein Lizenzschlüssel (Token) und die E-Mail-Adresse, auf die er ausgestellt wurde
Das Chat-Modell wird automatisch nach verfügbarem VRAM gewählt und kann im Admin-Bereich unter „KI-Einstellungen“ gewechselt werden.

Endnutzer-Lizenzvertrag

Bei der Installation ist der Endnutzer-Lizenzvertrag (EULA) zu bestätigen. Das Windows-Setup zeigt ihn vor der Installation, das Linux-Paket fragt per Konfigurationsdialog. Ohne Zustimmung wird nicht installiert.

Prüfsummen

Neben den Downloads liegt SHA256SUMS.txt. Vor der Installation vergleichen:

# Windows (PowerShell)
(Get-FileHash .\SovereignMind-Setup-<Version>.exe -Algorithm SHA256).Hash
# Linux
sha256sum -c SHA256SUMS.txt --ignore-missing

Nach der Installation

  1. App öffnen: http://localhost:5043 (der Port ist bei der Installation wählbar)
  2. Beim ersten Aufruf führt die App durch die Einrichtung: Lizenzschlüssel, Unternehmen und Admin-Passwort. Die Aktivierung läuft offline.
  3. Alles läuft als Dienst im Hintergrund und startet mit dem Rechner.

Lizenz und Wissenspakete

Den Lizenzschlüssel stellt der Anbieter aus, siehe Kontakt. Er ist an eine E-Mail-Adresse gebunden; bitte nicht weitergeben. Wissenspakete lädt der Admin direkt in der App unter „Wissenspakete“ herunter. Pakete mit Zusatzfunktion setzen eine passende Lizenz voraus.

Update und Datensicherung

Update: neue Version des Installers ausführen (Windows) bzw. sudo apt install ./sovereignmind_<Version>-1_amd64.deb (Linux). Daten, Schlüssel und Lizenz bleiben erhalten; vor dem Update wird ein Datenbank-Dump angelegt.

Sicherung: Die tägliche Sicherung läuft automatisch. Wiederherstellung und Deinstallation beschreibt das Betreiber-Handbuch, das mit dem Anbieter-Support ausgeliefert wird.

Bei Problemen bitte beim Anbieter melden und die Ausgabe des Installers mitschicken.
